Load or Paste Level 0 Character Data

How to use this site

  1. Get your character from ShadowDarklings. This link has specific settings for allowed ancestries, so accept the settings.
  2. Then click Create in the nav.
  3. Scroll down to GENERATION METHOD, and select Random 0.
  4. Under GENERATE RANDOM LEVEL 0 CHARACTERS, click Random 0.
  5. Scroll all the way to the bottom of the page to the EXPORT section.
  6. Make sure Copy to Clipboard is selected and click the JSON button.
  7. Paste that data into the field below, and click Render Character.
